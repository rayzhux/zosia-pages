Phase 2 — Root Cause Diagnosis

Why results suffer

The core bug is category confusion. Four different jobs keep getting blurred into one "search" concept.

Problem 1: No routing taxonomy

Each file defines its own rules for when to search vs fetch vs research. They drift independently. No single source of truth forces consistency.

Problem 2: doc-lookup is search-blind

When I need current docs, I guess URLs from training data instead of using Exa to find the canonical source. This is the single biggest quality gap.

Problem 3: No deep research trigger

"Deep research" has no explicit definition. No instruction says "when Raymond says deep research → deep_researcher_start with exa-research-pro." I default to basic search.

Problem 4: Cost optimization over quality

Cost appears in tool selection logic everywhere. "web_fetch first (free)" trains me to avoid the tools that produce better results. Quality should be the only routing signal.

Phase 3 — The Taxonomy

Four jobs, four owners

Every information need falls into exactly one of these categories. This taxonomy appears identically in all files.

D

Discovery

Find the right sources, pages, companies, or people

→ Exa Search

→
E

Extraction

Read a known URL and get its content

→ web_fetch / web-scraper

→
S

Synthesis

Combine multiple sources into one cited answer

→ deep_search_exa

→
R

Deep Research

Full multi-step investigation with comprehensive report

→ deep_researcher (pro)

Quick routing rules

The question Category Tool
"What's the current state of X?" Discovery web_search_exa or web_search_advanced_exa
"Read this URL for me" Extraction web_fetch → web-scraper cascade
"How does X SDK auth work?" Discovery + Extraction Exa finds docs → web_fetch reads them
"Compare X vs Y for our use case" Synthesis deep_search_exa
"Find GCC competitors for X" Discovery company_research_exa + web_search_advanced_exa
"Deep research the UAE aftermarket" Deep Research deep_researcher_start with exa-research-pro
"Research X" / "Look into X" Synthesis deep_search_exa (upgrade to deep researcher if complex)
"What are people saying about X on Twitter?" Specialized grok-x
"Find Chinese gov filings on X" Specialized kimi-cn

Change 4: Fallback Rules

Added to exa/SKILL.md

Explicit behavior when Exa underperforms.

  • If deep_researcher times out → fall back to deep_search_exa + manual Exa queries
  • If Exa returns no results for docs → try GitHub repo search via Exa, then web_fetch on repo README
  • If Exa and web_fetch both fail → report the gap honestly, don't fabricate
  • For critical claims → verify from primary official sources, not just Exa synthesis
